== Description ==

**AI SEO Assistant for Rank Math** analisa o HTML renderizado das suas páginas e fornece uma análise técnica completa de SEO, ajudando você a otimizar seu conteúdo para os mecanismos de busca.

Perfeito para quem usa **Elementor**, **Gutenberg** ou qualquer page builder, pois analisa a página final renderizada, não apenas o conteúdo do editor.

= ✨ Funcionalidades Gratuitas =

* 📊 **Análise técnica completa** - Contagem de palavras, H1, H2, links
* 🖼️ **Detecção de imagens sem ALT** - Identifica imagens que precisam de descrição
* 🔗 **Análise de links** - Conta links internos e externos
* 📋 **Verificação de Schema** - Detecta JSON-LD para rich snippets
* 💡 **Quick tips** - Sugestões práticas para melhorar seu SEO
* 🎯 **Status do Rank Math** - Mostra campos preenchidos/vazios

= 🔧 Como Funciona =

1. Abra qualquer post ou página no editor
2. Localize o metabox "AI SEO (Rank Math)" na sidebar
3. Clique em "Analisar Página"
4. Veja a análise técnica e sugestões de melhoria

= 📋 Requisitos =

* WordPress 5.8 ou superior
* PHP 7.4 ou superior
* Plugin Rank Math SEO instalado e ativo

== Installation ==

1. Baixe o plugin através do WordPress.org ou faça upload do arquivo ZIP
2. Ative o plugin através do menu 'Plugins' no WordPress
3. Acesse qualquer post ou página para usar a análise
4. Configure em **Configurações → AI SEO (Rank Math)**

== Frequently Asked Questions ==

= Preciso ter o plugin Rank Math instalado? =

O plugin funciona melhor com o Rank Math, pois verifica os campos de SEO dele. Mas a análise técnica funciona independentemente.

= O plugin funciona com Elementor? =

Sim! O plugin analisa o HTML renderizado da página, então funciona perfeitamente com Elementor, Divi, WPBakery e qualquer page builder.

= Qual a diferença entre Free e PRO? =

A versão FREE faz análise técnica e mostra sugestões. A versão PRO preenche automaticamente os campos do Rank Math usando Inteligência Artificial (ChatGPT).

= Como faço upgrade para o PRO? =

Acesse [nosso site](https://github.com/pereira-lui/ai-seo-wp-rank-math) para adquirir a licença PRO.
